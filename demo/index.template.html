Bangladesh daily electricity demand: from raw data to a model

One page, no server. Data and the trained model are inside this file.

Read before using the numbers.
  • This is a working result, not a final or perfect model.
  • Wind and cloud forecasts cover four zones only (Dhaka, Chattogram, Rajshahi, Sylhet), and the lead time is about 0 to 24 hours, not strictly day-ahead.
  • 2025 to 2026 was used earlier for load-shedding work and five demand days were printed, so it is no longer a clean holdout.
  • Gain over "tomorrow = today" is clear in 2025. In 2026 the interval includes zero.
